# ProctoCare Professional Website — Static Starter

Responsive multi-page HTML/CSS/JavaScript website starter for ProctoCare Hospital, Himatnagar, Gujarat.

## Included
- Animated homepage hero, service/condition cards, doctor profile placeholder, FAQs and appointment CTA.
- Condition hub and individual pages for piles, anal fissure, anal fistula, pilonidal sinus, constipation and anorectal abscess.
- About, treatments, doctor, patient guide, health library and contact pages.
- Trust/policy pages: medical disclaimer, privacy policy, terms, editorial policy, medical review policy, references and accessibility.
- Responsive navigation, reduced-motion support, appointment enquiry via WhatsApp.
- Titles/descriptions, canonical links, Open Graph basics, structured data, robots.txt and sitemap.xml.

## Run locally
Open `index.html` in a browser, or serve this folder with a static HTTP server, e.g. `python -m http.server 8000`.

## Before production launch
1. Verify phone, address, hours, services and appointment process.
2. Replace doctor placeholder with an approved photo and verified credentials/registration.
3. Use properly licensed imagery; consider self-hosted compressed WebP/AVIF for performance.
4. Have a qualified clinician review each medical page and add real author/reviewer names, credentials, actual review dates and page-specific sources.
5. Finalise privacy, terms and consent wording with the hospital and legal reviewer.
6. Verify claims about equipment, approvals, insurance, transport, follow-up, outcomes and “first/best” status.
7. The demo form opens WhatsApp and does not store submissions. Confirm number/consent or implement a secure server-side form.
8. Update canonical URLs for staging/production, submit sitemap in Search Console and Bing Webmaster Tools.
9. Test Core Web Vitals, keyboard accessibility, form flow, links, schema and redirects.
10. Add favicon, social sharing image and verified Google Business Profile details.

## SEO/AEO/GEO
Semantic headings, concise answers, internal links and structured data are starter foundations—not a ranking guarantee. Keep business details consistent, avoid thin duplicate location pages, and ensure structured data matches visible verified content. Google does not guarantee FAQ rich results.

Remote Unsplash images are placeholders; verify image rights and optimise before production.
